# 我如何用定时管线维护一个 673 模型的 AI 价格雷达

## 缘起

选 API 的时候我发现一件很别扭的事：同一个模型，在不同平台上的价格能差好几倍。DeepSeek、Qwen、GLM 这些模型几乎每家平台都在卖，但你要比价，就得一个个平台翻价格页——而价格还在变。

于是我做了个东西：把公开数据源里的模型快照抓下来，按家族分组，每 12 小时自动重算一次「当前最便宜的调用渠道」。现在它覆盖 673 个模型、73 家厂商，页面叫[福利情报](https://aimodle.cn/welfare)。

这篇文章写几个实现上的坑，以及为什么这个站可以做到「零人工维护」。

## 一、数据源：只选能自动化的

做这类工具，第一道坎不是写代码，是**判断哪些数据值得自动化**。

模型有统一注册表。models.dev、OpenRouter、LiteLLM、Epoch AI 这些源里，同一个模型有稳定的 ID（形如 `deepseek/deepseek-chat`）、统一的定价字段、发布日期、上下文长度。这意味着你可以写一条定时管线，12 小时跑一次，永远拿到最新价格。

反过来，AI 工具导航站做不了这个：一个 SaaS 工具的价格藏在它自己的后台里，没有注册表，今天免费明天收费，你没法自动感知。所以工具站只能人工维护——那就不是引擎，是苦力。

**结论：能不能自动化，取决于上游有没有结构化的注册表，而不是取决于你想不想。**

## 二、价格归一化：单位、精度、浮点

这是最枯燥但最容易埋雷的部分。

上游的定价格式至少有三种：

- OpenRouter 给的是 **$/token 的字符串**，比如 `"0.000005"`
- LiteLLM 给的是**科学计数法字符串**，比如 `"5E-7"`，也有直接给 number 的 `5e-7`
- models.dev 直接就是 **$/Mtok 的数字**，比如 `2.5`

要统一成「美元 / 百万 token」，直觉做法是 `parseFloat(x) * 1e6`。但这会引入浮点误差：

```
2e-7 * 1e6   // 0.19999999999999998
0.0000032 * 1e6  // 3.1999999999999997
```

这两个值都是 LiteLLM 里真实存在的，乘完就写进了快照，页面上显示 `$0.2` 看着没问题，但断言和比较会出鬼。

我的做法是先判断输入是字符串还是数字，按量级选有效位数（小于 0.1 保留三位、小于 10 保留两位），最后再转回数字。单价是用于**比较和排序**的，不是用于财务结算，所以保留三位有效数字就够了。

另外两个字面量坑：

- 负价格、零价格直接判非法（上游确实出现过 `0` 和 `-1`）
- `null` 不等于「免费」。没定价要显示「未收录」，不能显示 `$0`——把「未知」说成「免费」是数据诚信问题

## 三、家族分组与端点排除

把 673 个模型按输入价排序，第一档往往是 OCR 模型、embedding 模型或者某个 8B 的蒸馏版——它们价格极低，但对「我要调这个模型」这个需求毫无意义。

所以分了两层：

1. **家族匹配**：用正则把模型分到 DeepSeek、Qwen、GLM、Kimi、Llama 等簇里
2. **端点排除**：把 OCR、语音、图像、向量这类专用端点从价格榜里剔除

排除的正则长这样：

```js
const NON_CHAT = /ocr|image|audio|tts|asr|embedding|rerank|video|voice|speech|transcri|whisper|moderation|guard/i;
```

第二层不做的话，页面会骗人：它会把「最便宜」的徽章发给一个根本不能对话的模型。这个坑我在本地构建时抓到过一次——DeepSeek 家族的最低价标给了 `DeepSeek OCR 2`（$0.03），而真正能对话的模型是 $0.06 起步。

## 四、零维护：定时同步 + 变更日志 + RSS

管线的骨架是 GitHub Actions：

- 每 12 小时抓一次全部数据源
- 归一化、仲裁（同一字段多源冲突时按可信度取）、写快照
- 有闸门：模型总数骤降、必填字段覆盖率下滑、价格为零或负，都会拒绝写入并以非零退出码结束——宁可停下等人看，不能把脏数据上线
- 同步成功后比较新旧快照，把「新模型 / 退役 / 门面换代 / 冠军易主」写成一条变更日志，再自动往仓库的 issue 里追加一条「更新速报」

最后一块是 RSS。读者订阅 `/changelog.rss`，数据一有变化就能收到——不需要注册、不需要后端、不需要推送服务。

这套东西的价值在于：**我不用每天打开后台**。价格变了，页面自己变；模型退役了，榜单自己更新。人只负责两件事：改规则、看闸门有没有拦东西。

## 五、局限

老实说几个不足：

- 价格覆盖不是 100%，小厂商的定价经常抓不到，页面上显示「未收录」而不是猜一个数
- 家族分组靠正则，遇到命名不规范的模型会漏；目前 15 个家族覆盖了主要模型
- 汇率：统一用美元计价，人民币定价的源在管线里按上游给的美元值处理，没做实时汇率换算
- 「最便宜」只看单价，没算缓存命中率和批量折扣——实际账单可能不一样

## 六、现在长什么样

[价格雷达](https://aimodle.cn/welfare)现在每 12 小时自动刷新一次，15 个模型家族，每族列出输入价最低的前五档。同一个模型跨平台差价几倍的情况很常见，这个页面就是把这个差值摆到台面上。

页面上还有一页返佣福利榜——毕竟做站要吃饭。每条都标了复核日期，活动结束就下架，不挂过期的「送钱」承诺。

如果你发现价格抓错了，欢迎告诉我，我会修。
